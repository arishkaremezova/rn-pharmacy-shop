# Моя аптека

Учебное приложение на React Native, Expo, TypeScript и Zustand. Основа — [rn-stationery-shop](https://github.com/VakhromeevaKate/rn-stationery-shop).

Вместо канцтоваров используются 100 лекарств из `mocks/db.json`. Каталог и карточка показывают форму выпуска, дозировку, действующее вещество, производителя, рецепт и остаток. Корзина хранится в Zustand: количество можно менять, позиции — удалять. Добавить больше остатка нельзя.

В исходных данных нет цен и фотографий, поэтому приложение показывает количество препаратов без расчёта стоимости. Оформление заявки демонстрационное, данные никуда не отправляются. Корзина сбрасывается после перезапуска приложения.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm ci
npm run web
```

Откройте адрес из терминала. Для учебного входа введите логин `admin` и пароль `password`. Нажатие на препарат откроет подробную карточку, кнопка «+» добавит его в корзину. Корзина открывается кнопкой в правом верхнем углу.

Для просмотра на телефоне:

```bash
npm start
```

Откройте QR-код в Expo Go, совместимом с Expo SDK 57. Телефон и компьютер должны быть в одной сети.

## Вход через GitHub

Нажмите «Войти через GitHub». Скопируйте одноразовый код, нажмите «Открыть GitHub» и введите код на странице GitHub. После подтверждения вернитесь в аптеку и нажмите «Проверить подтверждение». Кнопка выхода в шапке каталога возвращает на экран входа.

Для этого проекта уже зарегистрировано OAuth-приложение. Серверный маршрут Expo обменивает код устройства на токен и проверяет профиль. Аптека сохраняет только идентификатор вошедшего пользователя. При локальном запуске маршрут обслуживает тот же процесс Expo.

На Android и iOS экран входа защищён от снимков и записи экрана. Пароль изначально скрыт, а значок глаза позволяет показать его. В браузере пароль всегда скрыт: браузеры не блокируют системные скриншоты.
